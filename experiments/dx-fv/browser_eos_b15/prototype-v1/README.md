# First prototype — interface counterexample, retained

This preliminary implementation passed ordinary documented-input science and produced the archived timings. Final review found that a fourth argument to public statePT, historically ignored, could supply the internal optional holder. The forged-holder counterexample is retained in `../evidence/interface-regression.json.gz`. Final candidate wraps the public PT entry to preserve its original three-argument interface and ignore extra arguments; the holder remains accessible only to internal PH calls. This version is not recommended for integration. Its source/patch, build hashes and all timing samples remain here. Preliminary candidate traces and browser summaries are prefixed `prototype-v1-` in evidence; their lossless references use the unchanged original controls. Main property receipt data are shared only after identical payload hashes verify. New final-version science and timing measurements replace no failed comparisons. Final reports and classification refer exclusively to the corrected final candidate. No accepted source was modified.
