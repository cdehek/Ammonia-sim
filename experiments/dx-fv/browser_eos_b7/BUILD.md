# B7 reproducible build and bounded replay

Use a fresh disposable environment with the same `/workspace` paths. Committed
evidence is immutable: scientific writers refuse existing outputs. An existing
delivery checkout can run `audit.py --read-only`; build/replay requires a fresh
copy of the harness with an empty B7 evidence/output directory. Never replace
historical B4C/B6 or delivered B7 artifacts. Whole-WASM hashes can depend on
source paths and generated ordering; each new artifact requires its own identity,
ABI and numerical audit.

## Preservation and delivery checks

Record current refs/PR identities, compare all protected identities with the
initial snapshot, verify only additive B7 files, then seal B7 and commit/push only
the explicitly authorized branch. Use `audit.py --refs remote-prepush.tsv` before
sealing, and `audit.py --clean --read-only --refs <post-push-ref-file>` after push.
The post-push receipt goes outside the committed tree; its actual final SHA,
clean tree and only-allowed-new-ref check cannot be self-embedded in that commit.
The delivered README and final response identify the exact commit.

Stop immediately on source provenance mismatch, unexpected patch content, unsafe
exception ownership, inaccessible repaired code, essential qualified-state
regression or a need to change inputs/guards/budgets. Preserve attempts and report
the blocker. Do not manufacture a pass through fewer exceptions. No further
repair, full A2, PR, merge or deployment belongs to this replay.
