# B7 bounded qualification design

Start from exact B6, preserve all historical files, and use two external source
directories with the pinned upstream tree. Reconstruct the exact four-patch B4C
control; apply the preserved Gate A patch once in the candidate. Compare all
1,782 hashes against both accepted manifests before compilation. No new scientific
repair is authorized. The four Gate B endpoint dispositions remain unresolved.

The original Embind surface has no configuration setter or phase-imposition
method. CoolProp's existing Configuration constructor reads
`COOLPROP_ENABLE_SUPERANCILLARIES=false` from its process environment and calls
the original boolean configuration mechanism used by native A1. The generated
Emscripten module implements `environ_sizes_get` and `environ_get`, but its private
`ENV` is not an exported runtime method. Supplying `Module.ENV` would not establish
activation. B7's isolated harness appends exactly that environment string through
the existing WASI imports, retaining all original environment strings. This is
runtime configuration of the original algorithm, not a thermodynamic input or
an alteration of its dispatch conditions. Both rebuilt artifacts retain original
source, exported APIs, compile/link flags and memory settings. Each full-VLE
instance receives the environment before its first configuration read; default
instances do not receive it. Instances are never switched after initialization.

This mechanism is additional isolated browser harness access, not a claim that
the unchanged historical general loader exposes a full-VLE selection. Verify its
actual environment callbacks, then obtain logging-only HSU_D_flash / saturation_D
traces in separately identified diagnostic artifacts and compare all diagnostic
outcomes with uninstrumented outputs. Diagnostics must record evaluated and final
cached coordinates and the caloric decision without extra EOS evaluation, solver
changes or modification of generic Newton/Brent. If actual access or parity
cannot be established, Gate 1 cannot pass.

Before any scientific browser matrix, compare both newly generated exception
implementations and imports/exports with the historical B6 ABI and pinned runtime
source. Use the exact B6 identity-tracking and matched generated begin/end-catch
algorithm only if compatible. Observe live object representation, reference zero
at escape, stack restoration, begin acquisition, end release/destruction and
bookkeeping baseline in actual Chromium and desktop WebKit. High-level internal
catches and JS-origin errors remain separate. No guessed pointer ownership.

All qualifications explicitly name B7 artifact identity and verify JS/WASM hashes.
Historical controlA remains the default selection for historical callers. No B6
or B4C loader is edited. Main-thread and worker tests use the same explicit maps.

Run no more than two compiler jobs total at a time. Bound full builds to 900 s,
record any unchanged continuation separately, and do not repeatedly rebuild
unchanged sources. Browser tests have outer process and Playwright deadlines.
Stop on provenance failure, unsafe exception ABI, inaccessible repaired path or
essential physical regression. Complete the report and preservation/push audit
even when a gate blocks downstream experiments. No Gate B, full A2 or deployment.
