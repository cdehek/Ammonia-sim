Fresh process/Worker sessions, matched diagnostic trace mode and original schedules. Distinguish fresh-JIT from warmed-engine sessions: warmed sessions perform bounded untimed model replays before the timed fresh fixture. Do not reuse model states across samples. Retain every valid sample; retain interrupted/error samples separately. No outlier trimming. Node CPU time is recorded separately from wall time. Browser performance.now() is wall time, not solver CPU.

Microbenchmarks use original supported pressure points and enthalpies: vapor, equilibrium two-phase, and an explicitly equal-count mixed input sequence. 3,000 untimed calls before 20,000 timed calls per class, same input order and checksums. These input distributions are experimental, not plant duty cycles. Include a measured transition-bearing warm interval and original versus added/fine schedule timing where resources permit. Report absolute paired ms savings and median paired percentages; group median ratios are not paired percentages. Report sample count, all ranges and dispersion; any bootstrap interval is descriptive for this small sample only.

Worker protocol follows B9D/B10/B11 session/sequence, compact snapshots, bounded histories, immediate termination and stale display protection where practical. Identical asset verification, source import, frozen table creation, initialization, request protocol and diagnostic level for both modes. Separately measure ready handshake, asset verification/import/table creation, model create/record, compute, compact projection, postMessage synchronous cost, response transport/dispatch remainder, main-thread handler and explicit display assignment. Do not call residual wall-time differences exclusive serialization CPU. Ping and identical snapshot echo controls characterize dispatch and clone scaling; no transport format advantage.

Main thread: independent lightweight 10 ms timer heartbeat, Long Tasks observer where available, actual dispatched UI button/tool events with measured acknowledgement, and in-flight Worker termination. Minimal harness responsiveness does not establish full workstation responsiveness. No layout claims from message handling.

Cold investigation compares frozen uninstrumented, counters-only and separately observed runs. Inspect extra wrapper/holder operations statically; obtain separate V8 optimization/deoptimization and GC receipts where available. Heap snapshots cannot establish allocation savings or causation.

Memory: bounded repeated resets/starts within the permitted horizon; record coarse process/browser heap and retained model/attempt/response/snapshot history counts.
