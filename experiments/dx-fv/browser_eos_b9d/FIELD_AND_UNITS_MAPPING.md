# Field and units mapping

Source: pinned workstation storage-app.js, storage-engine.js::record, live-schematic.js, storage-history.js::sample and storage-trends.js::series; A2 accepted coupled-model.cjs::record and authoritative cells. `r` means original record, `s` worker-owned A2 state. All available rows below are bounded table-backed research, effective uncalibrated conductance, not plant qualification. Timestamp is **r.seconds of that accepted endpoint** unless the row explicitly says retained historical timestamp. Availability means an honest separately labeled evaporator display; it never authorizes overwriting the existing field.

| Existing UI field/name | Existing source/model | A2 source | Scientific units → display / formula | Kind | Scientific meaning / different model / display now |
|---|---|---|---|---|---|
| Suction pressure; history pressures.outlet | storage r.vessels.outlet.p (else evaporator.p), separate suction partition | r.sections[0..4].p; terminal.p | bar absolute → bar(a) identity; psig=(bar(a)−1.01325)×14.503773773 | instantaneous | Five section pressures YES under section labels. Replacing suction NO; terminal bulk is not compressor protection evidence. |
| Discharge / condenser pressure; pressures.condenser | storage condenser bulk p | null | bar(a) → psig same formula if ever present | unavailable | Different equipment; no condenser or discharge state. NO. |
| Vessel temperature; temperatures.evaporator/outlet | storage recovered bulk T | r.sections[i].T | °C → °C identity; K=T+273.15; °F=1.8×T+32 | instantaneous | YES as section refrigerant temperature; no distinct suction vessel. |
| Compressor discharge temperature | observeCompressor.dischargeTemperature | null | °C → °F | unavailable | NO. Engine exports cycle solve, but A2 never invokes that plant calculation. |
| Actual outlet superheat / actualSuperheat | storage flows.superheat (interval documented when present) | r.sections[i].superheatK; r.terminal.superheatK; r.outlet.superheatK only if supported | K difference → °F Δ=1.8×K; no +32 | instantaneous A2 | YES as bulk section/terminal diagnostic; not sensor, compressor suction guarantee or existing interval average. |

| Tube / fin temperatures | no matching main dashboard gauge | r.nodes[id=tube-i / fin-i].temperatureK | K → °C or °F as above | instantaneous | YES new explicitly named coil readings. |
| Feed / drain / vapor flow | storage phase-selected valve port flow, often interval average | r.fluxes.faces[0] / faces[5].massKgS | kg/s, positive face direction inlet→sections→outlet | instantaneous endpoint | YES as signed coil inlet/outlet flow. | Evaporator heat / thermal powers | storage evaporatorHeatKJ and exchanger closures | r.fluxes.tubeRefrigerant[i], links, airLoad | kW identity; sum five tube rates if labeled | instantaneous | YES coil heat exchange; not condenser rejection or rated equipment capacity. |
| Energy accounting / balance | storage plant+room energyResidualKJ, work, externalHeat, compressor kWh | r.massResidualKg; refrigerantEnergyResidualKJ; thermalEnergyResidualKJ; combinedEnergyResidualKJ; ledger | kg / kJ identity; kWh=kJ/3600 only for explicitly identified energy | cumulative residual/ledger since initialization | YES coil+finite thermal-network closure only. Not plant-wide closure, electrical work or compressor energy. |
| Accepted clock / storage-clock | state.time, r.seconds | r.seconds | seconds identity, show enough decimals for .0001 s | accepted endpoint | YES independent session clock; never advance wall clock visually while worker pending. |
| Trends/history samples | storage.history samples at 1 s plus exact events; original IDs | detached accepted endpoint snapshots, separate session/version | same scientific units; conversion only on view | historical | YES own timestamp/version; no fabricated interpolation states or insertion into Live Plant history. |
| Model stop / storage-alarm | storage fault.kind/message/seconds/readings/limits | r.stop.kind/message/seconds/evidence; worker error separately | no numerical conversion | event at original accepted clock | YES numerical/domain classification only; evidence retained, stale previous snapshot distinguished. |
| Compressor state, speed, capacity, electrical demand | operations.compressorOn/speed; observeCompressor | null | null | unavailable | NO compressor dynamics/performance. |
| Feed valve command/opening and mode | storage controller, PI, operations | null | null | unavailable | NO actuator/controller in A2. Boundary PH and hydraulic connection coefficients are not valve positions. |
| High/intermediate/low-pressure receiver level/inventory | storage receiver/condenser and equipment concepts | null | null | unavailable | NO modeled receiver. Five-section mass or volume fraction cannot fill these gauges. |
| Equipment safety trips / pressure/discharge limits | storage equipment fault and profile thresholds | null | null | unavailable | NO. Numerical refusal is not equipment protection. |
| Plant-wide mass/energy balance, condenser rejection | storage complete illustrative circuit | null | null | unavailable | NO coupling to compressor/condenser/receivers. |

Absolute pressure may yield negative psig below standard atmosphere; do not clamp or relabel. The subtraction uses the workstation's fixed standard-atmosphere convention, not measured site barometric pressure. Show explicit units alongside every quantity. Display rounding and conversions never enter the worker solver. Historical/stale readings keep their own original timestamps; current fault time can be newer and must be shown separately. All unavailable equipment fields remain null with an explicit reason, not zero or a plausible approximation.
