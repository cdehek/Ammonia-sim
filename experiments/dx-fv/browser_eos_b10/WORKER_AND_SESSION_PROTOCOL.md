# Worker/session protocol

Protocol 1 and backend `A2-table-B9C-b67afb3` retain B9D ownership and ordering. Request: protocol/backend/session/requestId/sequence/type/args. Response: matching identity/type/sequence, acceptedVersion, accepted clock, scientific source identity, status/success, error/fault evidence, snapshot or explicit null, result and timing. B10 adds source identity to all responses and heat/step diagnostics to successful projections; no numerical control or algorithm changes.

Worker state never leaves as a live reference. The panel receives structured-cloned accepted projections, with at most eight unique successful versions in history. Test-only full details are not operator continuation state. Requests cannot accept replacement M/U/V or arbitrary boundary edits. Each new worker receives a fresh UUID session. Identical request IDs replay their stored response, altered duplicates and invalid sequence/version refuse. The client refuses overlapping advances. Old sessions, sequences or versions cannot replace readings or clear a newer equal-version fault.

States are uninitialized, initializing, ready, pending advance, accepted state, numerical refusal, confirmed modeled thermal-domain stop, stale previous accepted reading, lost, unqualified/missing backend and disposed. The panel separates last displayed accepted time, current worker accepted time if known, and failed-request target/evidence. Refusal never installs a new successful snapshot. An advance may retain genuine accepted substeps before stopping; whole-request rollback is not assumed. Only independently confirmed original domain evidence earns a modeled-domain label. No equipment alarm is inferred.

Stop latches future scheduling and queues after synchronous work; it cannot interrupt Newton mid-stage. Dispose queues, drops owner references and terminates after acknowledgement. Pagehide immediately terminates, cancels panel callbacks/listeners and clears request deadlines. Lost sessions retain stale readings, mark in-flight current state unknown, and require a new independent session. No silent restart or original-model fallback exists.

The normal interface supports only frozen cold/warm initialization and .0001/.0004/.0005-second advances (total .001 s), latest, compact original diagnostics, stop and dispose. Restart recreates the original fixture. Genuine numerical and 200/400 K fixtures require a test worker. Original C1 property-refusal experiments remain separate from the optimized owned-table worker.
