## Actual interfaces and faithful packaging

The accepted factory is `createCoupledModel(engine, options={}, observeAttempt=null)`.
It returns `create(config)`, `trial(state,dt,work)`, `advance(state,duration)`,
`update(state,patch)`, `record(state)` and `settings`. There is no reset, stop,
dispose, cancellation, async step or DOM API. `advance` synchronously performs
all original retries/TR-BDF2 work and returns an original record. `trial` does
not commit. Mutable accepted state includes cells, energies, ledger, spec,
clock, phase/boundary events and adaptive proposal history. Diagnostics include
work counters and traces. No controller exists in this dependency closure.

Use the twelve exact preserved CommonJS files in `../browser_eos_backend/accepted/`,
plus root engine.js/properties.json verified against A2 Git objects. A small
build script emits a registry of literal function wrappers around unchanged
source bytes. The resolver accepts only original relative `./file.cjs` imports,
caches module exports before execution, and rejects every unknown module.
`engine.js` follows its original CommonJS branch because module/exports are
provided. properties.json is parsed once without reformatting values before use.
No transpilation, minification, arithmetic transform, package substitution,
polyfill, import from later root model files, or runtime dependency is needed.
Both execution realms use the same generated registry bytes and resolver.
The original internal JSON clone in accepted code remains unchanged; B9 transport
uses structured clone and never round-trips scientific values through JSON.
All source slices, import edges and generated bytes will be hashed and audited.
If this closure cannot execute unchanged, stop at an architecture blocker.

## Ownership and scheduling

Main thread: experimental panel, UI input, heartbeat/frame sampling, worker
creation/termination, detached presentation data, request tracking and errors.
In worker mode it performs no engine construction/property/model evaluation.
Worker: imports/constructs engine and factory, owns the only scientific state,
executes advance/record, original trial commit/retry/failure logic and diagnostics.
One worker per disposable simulation session. Initialization failure installs no
model. Restart means a new session and worker with original fixture; no invented
model reset. The control uses the identical service in its own realm.

Each advance is one frozen duration request. Wall-clock scheduling cannot change
the duration, numerical settings or integration proposal. Commands execute FIFO;
async initialization is serialized through one promise queue. The client bounds
pending requests. Stop is an adapter scheduling flag, acknowledged only after an
in-flight synchronous advance returns. It does not write model.stop or fabricate
a physical trip. Later advance refuses, snapshot remains readable. Dispose drops
references at that same boundary; table model has no native destructor. Emergency
termination loses the disposable session, preserves only last received accepted
snapshot and cannot recover unknown in-flight work. It is not solver rollback.

## Protocol decision

See WORKER_PROTOCOL.md. Version, request ID, session ID, monotonic command sequence,
worker/backend identity, command type, outcome, model clock and accepted version
travel in each response. No raw model references, functions, live Error objects,
Embind handles or native exception pointers leave the owner. Snapshot creation
calls original record and clones accepted state for research comparison; it does
not recover a replacement property, change inventory or assign any state.

Duplicate request ID with identical session/sequence/content replays a cached
response; reuse with different content refuses. No advance executes twice.
Finite bounded cache refuses new commands when exhausted; disposal still allowed.
Out-of-sequence/session/backend/version requests refuse before dispatch. Client
tracks active session and accepted version, rejects unmatched replies, and ignores
older display snapshots. Replacing/disposing a client rejects pending promises;
old worker callbacks cannot write a new display. Crash/error/messageerror rejects
pending work and marks session lost. No fabricated success follows.

Object identity is tested inside each realm. Cross-realm agreement concerns exact
values/binary64 coordinates, never object-reference equality. ArrayBuffer transfer
is tested only on a disposable copy; authoritative solver buffers are never detached.
Nonfinite/signed-zero transport is tested explicitly; invalid scientific requests
remain invalid. Artifact serialization tags binary64 bits before JSON output.

## Frozen experiment before measurement

Use original `fixture('cold')` and `fixture('warm')`, both nonzero .60 kW/K total
exchange and original open flows. No config edits. Original default settings plus
`trace:true,timestepGrowth:'failure-aware'`, as in B8. Requested checkpoints are
0, .0001, .0005, .001 simulated seconds; durations .0001, .0004, .0005 in that
order. Record at each endpoint and compare full state/record plus observer attempts,
including stage/FD/line-search evidence. No performance-driven horizon extension.
Conservation and independent signed thermal-ledger audit apply at every record.
Actual phase crossing may be absent in this short workload; retain empty events
honestly and compare accepted boundary/event machinery without a coverage claim.

Gate order: main-thread baseline -> worker parity in Chromium and desktop WebKit
-> C1 failure/lifecycle -> matched timing -> optional B7 supported subset.
Any baseline parity failure stops downstream timing qualification.

Balanced timing matrix per engine: three sequential matched rounds; order main/
worker, worker/main, main/worker. Each mode gets a fresh page/context (cold page
and JS realm, no assertion of cold OS disk cache). Within each mode run cold and
warm model sessions for each frozen fixture, with identical output cadence/work.
No control/candidate physics overlap. Separately sample initialization heartbeat
and steady-state heartbeat, per-advance service/record/property/work cost, request
roundtrip/postMessage cost, rendering and payload bytes. Input acknowledgement is
a real panel button dispatched by an independent automation driver during work.
Sampling uses 10-ms heartbeat and requestAnimationFrame where available. Report
median/p95/max gaps without asserting desktop values apply to iPad.

C1 tests reuse the unchanged existing isolated wrapper/copies and preserved
scenario harness; clearly label injected faults. Preserve minimum 1e-9, Newton
30, 20 attempts/19 halvings persistent scenario and independent 200/400 K exits.
Rollback is checked before/after EACH rejected trial in worker-owned state,
including references. Native errors, if B7 used, are cleaned by unchanged reviewed
B7/B6-derived loader before safe immutable diagnostics cross the boundary.
No new generated ABI or EOS rebuild is planned.

Memory: table has no WASM allocation. Record available JS heap observations,
worker sessions/disposal, repeated bounded work; do not infer leak freedom from
high-water memory. Optional B7 reports module/factory/fetch/instantiate timings
only when actually observable; unavailable components are explicitly unmeasured.
